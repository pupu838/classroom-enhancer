# 课堂助手 0.9.0

安装入口仍为已有工作台。已安装 0.7.0 及以后加载组件的设备，重新打开学校回放页即可自动更新应用；播放过程中不替换代码。

- 画面：老师、教室、课件可单看、任意组合或三路同屏。调整布局支持上下、左右、主副、自由拖动及缩放，自动保存。
- 控制：画面下方的公共播放栏始终显示播放/暂停、前后10秒、进度和时间，不依赖点击某一路画面唤出。全屏也保留。
- 声音：公共播放栏单独选择老师、教室、课件音频，与可见画面无关。目标音轨缓冲时旧音轨继续；就绪并对齐后短交叉淡化。视频时钟不切换、不归零。网络异常不能保证新音轨立即可用。
- 降噪：听课中点击“开启人声增强”。通过原生 Audio 流播放和 AudioWorklet 中的 RNNoise 经典小模型 处理，48000 Hz、480采样帧。无需整节下载或采样底噪。增益在限制器之前；关闭降噪仍保留选中音轨。
- 下载：保存本节音频是独立、可取消的任务，使用当前选择声道。AAC 原样封装为 M4A；本地 Range 受限时通过已鉴权的固定学校媒体读取服务获取 AAC，不提交语音识别。下载状态不会停止播放或降噪。
- 本机字幕（试用）：点击“开启本机字幕”。音频从相同实时音频总线送往专用 Worker。Whisper tiny 多语言 q8，小模型约40 MB，运行组件约22 MB。使用单线程 WASM，避免实测 GPU 量化路径出现混合语言乱码；首次联网自动下载，后续使用浏览器缓存，系统可能清理缓存。约6秒一段，模型计算另有延迟；不是零延迟逐字字幕。
- 字幕不请求麦克风，不把课堂 PCM 或学校凭据传给模型下载站。本机只下载公开模型/运行组件。云端字幕依旧是用户另行选择的功能。

iPadOS 26 Safari 已支持 WebGPU。M1 可以尝试本机小模型，但还需实际 iPad 验证识别耗时、耗电和内存，不能用 Windows Chrome 结果冒充。

## 验证

- 学校实际课程：Chrome 接入三路原生流式声音及 RNNoise，切换音频保留视频进度，2倍速继续播放；增强路径不调用整节下载。
- 合成三路：竖屏上下布局、自由拖动缩放与顺序、全屏舞台撑满、公共播放栏、键盘调整布局不误跳进度。
- 实际 RNNoise WASM：10秒连续噪声运算约0.3秒，输出有限，噪声能量下降。此项是算法/性能测试，不等同于课堂主观听感。
- 学校实际课程完整保存24,170,253 字节 M4A，2756.993秒。发现并修复原生播放器缓存导致 Range 返回整文件长度的问题，下载使用 no-store 绕开。
- 真实课堂本机 CPU 识别成功产生中文，6秒音频处理约2.5秒（当前电脑）。小模型错字多、没有人工核听，结果不作为准确率保证；M1 iPad 速度待实机测量。
- 自动检查覆盖实时声音切换缓冲时旧声保留、时间偏移、暂停/缓冲/跳转、降噪开关、音量、下载独立、本机字幕有界队列及跳转清空、自动更新散列与回退、后台鉴权和媒体读取范围限制。

## 依赖

Artplayer 5.4.0（MIT）、MP4Box.js 2.3.0（BSD）、Jitsi rnnoise-wasm 0.2.1（Apache-2.0 包装，RNNoise 本体 BSD）、Transformers.js 3.8.1（Apache-2.0）、ONNX Runtime Web 固定版本。第三方许可证位于 portal/tablet/vendor/。运行时小于原0.7加载组件的1.5MB限制；经典小模型随应用加载，避免额外等待或要求用户重新安装加载器。
