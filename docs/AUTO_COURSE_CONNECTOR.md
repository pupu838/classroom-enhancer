# 自动选课与音频提取连接器 0.4.0

目标：学校原页面登录 → 自动读取当前学期课程 → 选课次 → 自动提取音轨并试听/保存；电脑与 iPad 两端均提供安装入口。

## 实现方式

EdgeOne 只托管工作台与连接器发布文件。学校页面中的连接器调用学校已有请求封装（认证仍由学校内部处理），读取课程、允许访问的回放页和对应媒体。只向打开学校页面的已知工作台窗口发送课程元数据、进度及最终音频 Blob；严格验证 origin、窗口对象和随机 channel。密码、Cookie、sessionId/x-Token 不被导出。

媒体服务器在真实请求中允许 Origin 为学校页面的 CORS 读取。连接器在学校 origin 中发起流式请求，使用 MP4Box.js 2.3.0 将 AAC 音轨重新封装为 M4A，移除视频，不做 AI 推理或重编码。音频无需经过 EdgeOne 服务器，也没有公开下载代理。

## 一次性配置

- 电脑 Edge/Chrome：工作台下载 `Classroom_Connector_Edge.zip`，解压后加载该扩展。可以与旧 Classroom Enhancer 同时使用；仅匹配学校学生端路径，MAIN world 执行，不请求新增媒体主机权限。
- iPad/iPhone Safari：安装官方 Userscripts 扩展，将 `Classroom_Connector.user.js` 导入其目录或通过 Safari 中的扩展安装提示导入，仅允许学校云课堂。显式 `@inject-into page` 与 `@grant none`。无需每节课复制 JSON 或运行 Python。
- 从工作台点击连接，在学校原页面登录。已配置的连接器自动读课程。若浏览器切断 opener 或暂停后台标签，可直接使用学校页面右下角的“课堂音频连接器”选课/提取。

## 当前限制

真实账号 API 的连接器执行和 Safari 实机尚未验收，不能把模块测试当成端到端通过。浏览器自动化不支持本次扩展安装；需用户在自己设备完成配置才能实测。

iPad 需要提取时保持学校页面前台。当前学期仅自动选择日期覆盖今天的学期，不猜测其他学期。每页30个课次，支持继续分页，每批最多20个已枚举课次。仅处理学校标注的可发声音轨，按最低 voicePriority 选择同一分段的一路；无法找到时明确停止。删除或未公开的课次不进入选择列表。单视频输入上限800MB；浏览器内存性能仍需 iPad 实机验证。

目前仍会读取源视频数据；输出只有 AAC 音频，大小不代表网络只下载了音轨。连接器不修改课程、点赞、收藏、观看记录，不把提取作为已完成观看。

## 已完成验证

- 使用本次真实课程391856150字节MP4，执行与浏览器共用的 JS 模块，生成46434660字节M4A；ffprobe 验证只有1路 AAC 音轨，时长2760.042167秒。
- 合成学校API/DOM测试：自动课表、选课、公开/未删除回放过滤、无写操作、未导出登录凭据。
- 合成工作台测试：origin和channel限定握手、课程/课次展示、选择后发送提取请求；不可信来源消息被拒绝。
- 以上不证明当前学校账号接口实时可用、跨窗口握手或 iPad 实机兼容。

## 依赖与构建

`npm install` → `npm run build:connector` → `npm run test:connector`。
MP4Box.js 2.3.0 固定版本，许可证随脚本和扩展发布，见 `MP4BOX-LICENSE.txt`。源文件 `scripts/school-connector.mjs` 和 `scripts/audio-remux.mjs`；构建产生 portal 脚本与 ZIP。
