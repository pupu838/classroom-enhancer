# iPad 字幕助手 0.6.0

正式安装页：https://classroom-enhancer-global-5rcwipvd.edgeone.dev/

## 使用

1. iPad Safari 启用 Userscripts，允许访问安装页和学校课堂网站；停用旧版课堂脚本，避免重复运行。
2. 从安装页安装 Classroom_iPad.user.js，刷新页面。
3. 点左下角“连接字幕服务”，输入私下提供的一次性连接码。请在准备使用的 iPad 上连接；连接码使用一次后失效。
4. 登录学校课堂，点右下角“课堂字幕助手”，选课程、课次，再点“提取并生成字幕”。
5. 保持页面前台，直到显示“整节课音频已确认提交”。之后可关闭页面，云端继续处理。回放同一课次时自动加载字幕。

不需要手动保存或上传音频，也不需要电脑保持开机。学校登录由用户在 iPad 完成。

## 当前范围

字幕是普通语音识别结果，尚未经过教材校正或人工核听。保存在私有字幕服务，未接入Google Drive。多独立录制分段课次暂不支持自动字幕。

前台每20秒查询任务。独立后台约每15分钟补查已提交任务，调度可能延迟；不会自动创建新识别任务。腾讯回调未能可靠验收，因此不以回调作为保存保障。GitHub公开仓库若60天无活动，定时工作流可能被停用，需要维护者重新启用。已关闭ASR后付费，额度耗尽时任务可能失败。

## 运维

源码分支：cloud-pipeline-v0.5。默认main分支单独配置 .github/workflows/tablet-subtitle-save.yml；后台调度依赖加密密钥 CLASSROOM_SWEEP_TOKEN。EdgeOne中提供同值 CE_SWEEP_TOKEN，以及腾讯专用子用户凭据、CE_API_TOKEN和CE_PAIR_CODE。腾讯子用户仅有CreateRecTask和DescribeTaskStatus权限。

所有密钥只留私有配置与托管环境。公开脚本不包含腾讯密钥、服务口令或连接码。云端转录按课次ID匹配；请勿把个人连接码公开分享。新增设备需重新生成一次性码。
