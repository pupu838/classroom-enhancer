# 0.2.0 测试报告

日期：2026-10-05。此版本是 v1 开发预览。

## 已通过

[Windows Edge 自动化运行记录](https://github.com/pupu838/classroom-enhancer/actions/runs/37333720061) · Edge 153.0.4234.48 · windows-latest。

测试使用真正的 Microsoft Edge 加载解压后的扩展，内容脚本由浏览器自动注入，并非把普通网页脚本注入当作安装成功。页面、音频和模型响应为合成夹具，未使用学校真实课程。

- 清单及所有引用资源存在；浏览器加载扩展并自动注入。
- 原字幕更新、字号设置、偏好保存、元素全屏包含字幕。
- 页面已有总结和章节读取，点击章节跳转并保持暂停。
- 后台 service worker 调用模拟本机接口、解析大纲、校验引文并区分来源。
- 拒绝其他课次的大纲导入，保留当前结果。
- 扩展资源中的 AudioWorklet 实际加载，采样完成后恢复原声。
- 跨域处理被拒绝时保持原视频未静音。
- 关键词搜索；无未捕获浏览器异常。
- 确定性 DSP 合成噪声功率比约 0.272；这不代表真实课堂听感。
- Chromium 153 页面回归和 DOM/mock 回归也通过。

## 最终包复现

构建固定 UTF-8、LF 和 ZIP 元数据。持续集成重建后要求生成文件及下载 ZIP 与提交内容一致；同时测试仓库根目录和专用 ZIP 解压目录。参见仓库 Actions 最新运行。截图和当次包保存在 edge-test-evidence 工件中。

首轮测试成功加载扩展，但测试音频服务缺少字节范围响应导致无法跳转。补齐 Range 响应后同一章节跳转通过。此处保留失败原因，避免把修复测试夹具误写成修改学校播放器。

## 尚未通过真实现场验收

- 学校实际媒体 CORS、完整字幕覆盖、真实人声听感及长时间倍速同步。
- 真实本机模型的摘要质量、专业术语准确性、跨片段去重与大纲质量。接口测试使用模拟响应。
- iPad Safari / Userscripts 的触控、音频、全屏与系统限制。不能用 Edge 测试替代。

以上尚未完成，不能称为双端 v1 最终验收完成。测试不公开学校课程、登录信息或个人数据。
