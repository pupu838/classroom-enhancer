# 课堂助手0.8.1修复记录

本版修复实际学校页面中播放器和音频按钮不能使用的问题。

- 统一识别学校回放地址中的 id、videoId 等课次参数。播放器、音频增强和字幕使用同一课次。
- 媒体下载优先使用浏览器携带学校来源信息的分段请求；无法跨域读取的服务器保留扩展桥接入口。单次最多4 MiB，不把整段视频读入内存。
- “听课”增加“保存本节音频”；课程列表增加“提取并保存音频”。保存音频和音频增强不要求连接字幕服务。生成字幕仍需连接。
- 播放器按钮显示失败原因与等待状态，不再静默无反应；学校资料读取超时可以重试。
- 已装0.7加载组件的设备继续自动获取应用更新，无需下载新脚本。重新打开学校页面，若提示新版已准备，再刷新一次，确认标题为0.8.1。

真实课程验证：在Chrome中加载本次完整脚本，使用学校当前登录，成功接入老师、教室、课件三路；验证播放/暂停、进度条拖动、单路/两路/三路、倍速、静音，以及纯音轨增强。约1.4 GB源录像完整提取并保存了约46分钟M4A。

三路画面+1.5倍速的12秒连续采样中：音轨和主视频最大偏差约0.085秒，三路最大偏差约0.133秒，没有新增等待、暂停或纠偏跳转，也没有检测到静音样本。开启底噪处理后再切换视角和1.75倍速，音轨继续播放，没有新增等待或纠偏跳转。

这些是当前真实课程的电脑浏览器结果，不能代替iPad实机测试，也不代表所有课程都已经验证。底噪应在老师未讲话时采样；识别和降噪无法恢复原录音未录清的内容。
