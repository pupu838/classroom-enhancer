# 课堂助手 0.10：整课字幕

2026-10-20：用户取消显卡降噪，交付范围改为整课字幕上线。三路视频、三路原声音频、布局和独立音频下载保留；本机声音调整仍为默认关闭的可选功能。

## 使用

1. 已安装统一脚本0.7.0及以后的设备，关闭旧学校回放标签页，重新进入，面板应显示0.10.0；无需重新安装或更换连接码。
2. 打开一节具体回放，在“课堂助手 → 听课”顶部点“生成本节云端字幕”。也可到“课程与字幕”批量选择。
3. 准备和上传期间保持学校页面在前台。看到“音频已完整提交，可以关闭页面”后可离开，后台继续处理。
4. 返回同一课次自动恢复进度、加载已完成字幕。上传中断则继续提交未确认分段。完成后重看不重新识别。

## 改动与计费

- 移除学校播放器中的Moss云端降噪按钮、服务检查、音频窗口读取及处理链路。正式后台不再注入GPU网关；旧客户端也不能通过此后台开启GPU。
- 将整课字幕操作放在听课面板顶部。字幕完成后两个原有查询入口均停止定时重复查询；手动刷新和切课恢复保留。
- 切课时立即取消准备，并在每个异步准备步骤结束后复核课次，避免提交上一节课。
- 继续使用腾讯通用录音识别16k_zh，优先抵扣账号免费额度。没有开启自动后付费或购买资源包。大模型2.0短测被资源额度检查拒绝，没有取得任务编号，不切换到这个模型。
- 2026-10-20控制台实查普通录音识别本月剩余7.59小时，期限10月31日；这是当时账号余量，不是网页承诺额度。余额显示4.44元，历史GPU测试可能延迟出账。GPU函数最大独占配额0，无预置实例，已关停。

## 证据与限制

- 线上既有2756.993秒课程，返回complete、8/8、1124条持久字幕；只读取已有结果，无新识别提交。
- 发布短测使用8秒真实课堂AAC，按正式前端重封装、分段、上传、腾讯通用API识别、保存，返回1/1完成、3条带时间戳字幕，媒体时长8.064秒。没有本机识别模型或GPU调用。
