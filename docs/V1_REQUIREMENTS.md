# Classroom Enhancer v1 需求基线

> 历史基线（2026-10-05）：保留原始目标与当时实现边界。2026-10-06 的数据可靠性与开发顺序修订见 [修订方案](V1_REVISED_PLAN.md)。修订文档不是已实现功能声明。

2026-10-05 确认。目标：在不改变学校原云课堂的情况下，为课堂录像增加人声增强、全屏字幕、AI 课程大纲、重点识别和知识点时间轴导航。

## 用户体验

- 看之前：快速了解这节课讲了什么、课程结构和复习重点。
- 看之中：人声更清楚，字幕覆盖在视频上，全屏与倍速可用。
- 复习时：搜索或点击知识点，直接控制学校原播放器跳转。

## 范围与验收

| 能力 | 验收要求 | 0.2.0 实现边界 |
|---|---|---|
| 人声增强 | 开关、强度、原声恢复，不修改学校原视频 | 本机滤波/增益/限幅与采样频谱降噪；非 AI 人声分离；取决于媒体 CORS |
| 字幕 | 原字幕复用，普通/元素全屏覆盖，可调样式，倍速同步 | 读取 `.captions-right`；原生系统视频全屏使用替代入口 |
| 课前大纲 | 简洁概述、知识结构、概念/公式/例题、重点依据 | 默认整合学校已有总结和导航；可选本机模型分段分析或导入 JSON |
| 时间轴 | 带时间点的可点击章节、搜索、当前章节标识 | 原视频跳转；多路已加载视频同步定位；不强制开始播放 |
| 双端 | Edge 与 iPad Safari | Edge 扩展；Safari Userscripts。iPad 可用学校导航/导入大纲，本机模型调用在 Edge 中使用 |
| 安装 | 解压后所选目录直接存在 manifest.json | 仓库根目录和 Edge 专用包均可加载，兼容旧 edge/ 目录 |

## AI 事实边界

- 学校已有 AI 结果显示来源，不能保证校方转写和总结无误。
- 关键词命中显示为“强调线索，待核对”，不冒充 AI 分析。
- 新模型结果显示 AI 来源；优先级星级是 AI 复习建议，不是考试承诺。
- 老师明确强调仅能基于原字幕匹配的逐字引文和时间点，仍需核对录音。
- 分段处理当前读取的字幕；显示读取段数、最后时间与总时长，不能声称未加载内容已分析。
- 错课次、乱序、负数或越界时间拒绝导入；本机分析的 start 必须对应输入字幕时间。
- 失败或取消保留之前结果，不用未完成片段替换完整结果。

## 成本、数据与架构

原云课堂 + 浏览器扩展。无视频重新托管，无默认外部 AI 账号，无默认付费调用。音频在客户端处理。扩展可读取页面已提供的转写和导航；可选 localhost:11434 本机 Ollama；或由用户主动导出字幕后交给其选择的 AI，再导入 JSON。

默认不传输字幕到第三方、不记录认证凭据、不下载持久化课堂视频。音频增强会额外请求相同媒体以获得独立音轨，可能增加流量，但不上传/托管视频。

## 尚需真实环境验收

学校页面现场读取、真实录像的音频 CORS/听感/同步、Windows Edge 手工安装、iPad Safari 触控/全屏。自动化测试应明确真实浏览器、模拟页面、模拟模型各自覆盖范围，不将其中一种冒充另一种。
