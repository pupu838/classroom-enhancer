# 0.3.0 开发进展

2026-10-06。按用户要求继续使用学校原播放器，不从零开发新播放器。当前实现增加本地音频处理器、字幕数据包导入和修订，不把学校视频上传到 B 站或 YouTube。

## 本次实现

本地文件选择窗口与 CLI；faster-whisper 本地模型适配；FFmpeg 选择音轨、分段和重叠上下文；输入/参数指纹与断点续处理；部分覆盖记录；原始分段输出保留；字幕数据包。

扩展支持按课次导入、覆盖与时长校验、来源切换、时间偏移、修订另存、IndexedDB 保存、导出迁移、当前来源参与 AI 分析、大纲过期提示及跳转阻止。学校播放器继续承担视频播放，未经验证的多路视频不强制同秒同步。
