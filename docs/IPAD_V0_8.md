# 课堂助手0.8.1：三路同步回放

安装页：https://classroom-enhancer-global-5rcwipvd.edgeone.dev/

已经安装0.7.0加载组件：重新打开学校课次自动检查更新；若“设置”显示新版已准备，再刷新一次即可，不必重新下载脚本。0.6及更旧版本需要从安装页更新一次原脚本。

新播放器使用MIT许可的Artplayer，提供B站风格的操作界面，不是B站官方播放器。

## 怎么看

打开一节课，视频资料加载后自动接入。顶部有“单画面 / 自由组合 / 三路同屏”。

- 单画面：点老师、教室或课件，保留当前进度切换。
- 自由组合：点三个角度按钮勾选或取消，至少保留一路，可以任意组合两路。
- 三路同屏：同时显示全部可用角度。

底部只有一条进度条，暂停、播放和拖动进度作用于全部画面。顶部倍速、音量、静音同样共用。声音始终只有一份；启用纯音轨增强后，调整声音或切换画面不会反复重建增强音轨。

“多画面全屏”保留全部选中角度及课堂助手。原生iPad视频全屏可能只显示单路，请用这个按钮。

## 同步与恢复

始终保留同一个主时间轴，切换视角仅改变显示。学校给出可靠录制起始时间时，先补偿各路起始偏移；之后以轻微速度校正小幅偏差，只有较大偏差或主动拖动进度时才跳转。该方式不是逐帧硬同步。

副画面缓冲时显示提示，其余画面和主音轨继续；主画面缓冲时其他画面暂停等待。未显示的副画面暂停以降低消耗。三路同屏会同时读取三路视频，较单路需要更多带宽与解码资源。

顶部“恢复学校播放器”会带回当前进度及音量。也可以在课堂助手“设置”里重新启用多视角播放器。课次切换时释放旧播放器，避免后台重复播放。

若学校返回多段独立录制或时间信息异常，本版保留学校播放器，不把无法确认对应关系的片段拼在一起。学校若缺少一路，会显示“无画面”。

云端字幕继续以同一主时间轴显示；可读取的原生字幕轨也可显示。学校专用网页字幕若无法读取时间数据，将不沿用已停止原播放器留下的旧句，避免字幕错位。

## 验证边界

通过：录制起始时间偏移映射、三路同步、切换保持进度、单声音、暂停/倍速/缓冲、增强音频不重建、静音与音量、全屏包含三路和助手、恢复学校播放器保留进度、导航清理。

实际Chrome浏览器合成三路测试：1.75倍速持续采样最大时间差约0.14秒；直接拖动进度时三路均到13秒；切换成单路和任意两路不重置进度。实体iPad Safari和当前学校实际课程源仍需用户复测，不能由电脑合成测试替代。
