# EdgeOne 工作台与音轨获取验证

2026-10-16。工作台为 `portal/`，部署到独立的 EdgeOne Makers 项目，不替换文献库。

## 实际验证

- 统一身份认证手动登录后，新打开云课堂入口直接显示已登录页面；已验证当前浏览器会话复用。
- 学校提供“7天免登录”，但未验证完整有效期、关闭浏览器后的恢复或无人值守账号密码登录。
- 一节实际课程三路 MP4，约 46 分钟，播放器能正常播放。
- 不带 Referer 的媒体 HEAD 返回 403；相同媒体带 `Referer: https://ylb.nwafu.edu.cn/` 的 Range 请求返回 206 和合法 MP4 字节。该结论仅针对本次测试的媒体主机，不能推断所有课次相同。
- FFmpeg 直接读取相同来源并抽出 30 秒 PCM WAV（16kHz，单声道）。文件有效性由 ffprobe 验证，尚未做课堂语音准确率/可懂度验收。
- 整段 MP4 已实际下载，大小 391856150 字节，容器时长 2760.05 秒。课程媒体与私有回放 ID 不提交仓库、不发布到公共站点。

## 当前使用

1. 从工作台打开学校云课堂；学校 SSO 负责登录与会话续接，工作台不接收密码。
2. 打开并播放课程，使用工作台提供的采集书签下载 JSON。采集读取 DOM 中已加载的 video/source，不读取 Cookie、存储凭据或应用内部状态。
3. 导入 JSON，选择实际有声音的画面。任务只在浏览器内解析，不上传服务器。
4. 下载 `fetch_audio.py`。安装 Python 与 FFmpeg，在电脑执行工作台生成的命令。下载时附学校 Referer，再抽出单声道 MP3。

书签采集尚未完成真实浏览器交互验收，iPad 兼容性尚未验证。已有扩展提供字幕覆盖等功能；这里的静态工作台不是浏览器扩展的替代品。

## 为什么没有公开音频代理

发现 Referer 可读取某条媒体，不等于应公开提供任意课程下载接口。当前没有配置访问控制的云端音频代理，媒体也不会作为网站静态资源上传。后续若启用云端处理，必须先配置用户访问控制与私有对象存储，再接异步 ASR；不得把学校密码、Cookie 或课程内容写进公开 GitHub。

## 部署

部署入口复用 `pupu838/chatgpt-share-text-extractor` 仓库已有 Actions Secret，工作流 `deploy-classroom-edgeone.yml` 读取本仓库 main 的 `portal/` 发布独立项目 `classroom-enhancer-workbench`。不复制、不输出 API Token。修改工作台后可手动重新运行该部署工作流。
