# 课堂助手 0.7.0

安装页：https://classroom-enhancer-global-5rcwipvd.edgeone.dev/

这次更新原脚本一次，不要先删除，以保留已经连接的字幕服务。学校页面右下角只保留“课堂助手”。里面有听课、课程与字幕、设置三个页签。

## 听课

打开一节回放，播放正常后点“准备并启用音频增强”。首次需从学校视频提取并缓存纯音轨，期间继续播放原声，保持学校页在前台。准备完成后切换到增强音频。之后重听同一节会复用缓存。

不再播放第二份完整视频。小幅同步偏差通过轻微调整速度纠正，避免反复跳转造成断续。拖动原播放器进度或改变倍速，增强音频会跟随。若增强音轨卡住，自动恢复原声。

建议先用低降噪强度；只在老师不说话、仅有环境底噪时点“采样底噪”。聊天声和原录音里没录清的词无法可靠恢复。

## 字幕与设置

“课程与字幕”内选课程、课次后提交。已完成的课次直接读取结果，不重复提交。音频缓存与听课增强共用。字幕仍是未经教材校正的识别稿。

“设置”里连接或更换字幕服务，并查看自动更新状态。纯音轨增强只需要学校登录，不要求连接字幕服务。

## 自动更新

安装本版后，稳定的加载组件在每次打开页面时检查应用更新，校验文件摘要后保存。播放期间不会替换正在运行的版本；如果显示“新版已准备”，重新打开页面即可使用。更新网络不可用或文件校验失败时，保留上一次可用版本。未来若增加浏览器权限或改变加载组件本身，仍可能需要一次组件更新。

## 验证情况

通过：连续音频处理无逐帧数组分配、波形连续性、底噪衰减、小幅偏差不触发硬跳转、拖动进度同步、卡住后恢复原声、统一面板、自动更新校验与离线回退。

电脑 Chrome 实际播放：纯 M4A 音轨、1.5及1.75倍速、拖动进度、底噪采样后，连续采样未检测到静音断点，音画偏差约0.06秒。此测试不能代替实体iPad Safari测试。
