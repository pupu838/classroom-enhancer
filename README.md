# 西农云课堂增强 0.1.0（试用版）

为西北农林科技大学云课堂制作。包含电脑 Edge 扩展与 iPad Safari 用户脚本。

## 当前完成与验证范围

已登录实地确认：播放器为 Video.js；共三路 MP4；网站字幕位于视频外 `.captions-right`，没有原生字幕轨道；媒体来自 `lzm01.nwafu.edu.cn`，与页面不同域。

已实现：同步网站现有字幕、字号/颜色/透明度/位置调节、触屏拖动、带字幕全屏、网页铺满、设置记忆；本机高低通滤波、人声频段增强、增益与压缩限幅、采样底噪后的频谱降噪、独立增强音轨和恢复原声。

已验证：JS 语法；DOM 与模拟媒体测试（字幕更新、样式保存、全屏容器、铺满回退、原声恢复、音频加载失败不接管原声）；DSP 合成底噪测试。尚未完成真实 Edge/Safari 端到端与真实课堂听感验证。云端浏览器中课堂视频未载入媒体数据；本地测试环境浏览器安装被网络限制，因此不能把这些测试当作实际设备兼容性保证。

这是可安装的试用版，不是已经在两台设备验收完成的成品。特别是音频跨域许可与 Safari AudioWorklet，需要在实际播放环境验证。

## 电脑 Edge 安装

1. 解压本压缩包，保留整个文件夹。
2. 在 Edge 地址栏输入 `edge://extensions`。
3. 打开“开发人员模式”，选择“加载解压缩的扩展”。
4. 选择本包中的 `edge` 文件夹（该文件夹内直接有 manifest.json）。
5. 刷新云课堂，打开任意课堂录像。视频页面右上方出现“课堂增强”。
6. 点击它，选择“带字幕全屏”。字幕可用鼠标拖动，也可用面板滑块调整位置。

不要同时用脚本管理器再次装同一功能。此扩展只匹配学校云课堂路径，不请求其他网站、Cookie、麦克风或屏幕录制权限。

## iPad Safari 安装

1. 安装 App Store 的 **Userscripts**（开源项目 quoid/userscripts，链接见下）。
2. 打开 Userscripts，按应用提示选择存放脚本的文件夹。
3. 在 iPad“文件”中解压本包，把 `Classroom_Enhancer.user.js` 放进刚才选择的脚本文件夹。文件名必须保持 `.user.js` 结尾，不能变成 `.txt`。
4. 在系统设置中启用 Safari 的 Userscripts 扩展；进入学校云课堂后通过 Safari 扩展菜单允许其访问 `ylb.nwafu.edu.cn`。
5. 刷新课堂页面，开始播放，点击右上方“课堂增强”。
6. 使用插件的“带字幕全屏”；若浏览器不支持则自动网页铺满，也可手动选“网页铺满”。

iPad 系统原生视频全屏不能保证带入自定义网页字幕，因此不要使用原生视频控件的全屏入口。如果学校只给手机布局，可在 Safari 选择“请求桌面网站”再刷新。

Userscripts：https://apps.apple.com/app/userscripts/id1463298887
安装说明：https://github.com/quoid/userscripts/blob/main/README.md

## 音频使用

1. 确认原视频能正常播放。打开“课堂增强”，点击“启用音频增强”。
2. 插件以 anonymous CORS 模式额外加载同一媒体的独立音轨。只有成功加载、建立处理链后，才静音原视频。增益初始为 6 dB，可自行降低。
3. 在老师没有讲话、仅有稳定背景噪声的片段，点击“采样底噪 1.5 秒”。采样完成后启用频谱降噪。采样包含人声会误伤老师声音，应重新在纯底噪片段采样。
4. 初始强度为 1.2，声音发闷或出现水声时降低强度。强度为 0 时近似不做频谱衰减，仍保留滤波、增益和限幅。
5. 点击“恢复原声”对比。切换课程、原音轨或离开页面时会停止增强；需要时再次启用。

降噪处理完全在本机进行，不上传音视频，不调用付费接口。独立音轨可能增加网络流量。不是 AI 人声分离，主要针对稳定底噪、低频轰声、高频嘶声和声音偏小；无法承诺去除其他人说话、混响，或恢复录音中丢失的词。

音频初始通过视频同步时间、倍速及原播放器音量，后续跟踪播放/暂停/跳转/倍速；独立音轨存在小幅同步误差，需要实际试听确认。若播放器主动切换音量或声道导致静音状态变化，会恢复原声。

## 出现问题怎么办

- 没有“课堂增强”：确认进入了课堂录像页（不是课程列表）、刷新页面、检查扩展对该站点的权限。
- 没字幕：先检查学校页面原本有无字幕；该版不会重新识别语音，也不会纠正学校字幕里的错字。
- 全屏仍没字幕：退出系统原生视频全屏，使用插件的“带字幕全屏”或“网页铺满”。
- 提示跨域/加载失败：学校媒体服务器可能不允许 CORS，或媒体地址过期。此版本继续使用原声，不会绕过服务器限制。字幕仍可用。把面板提示截图发回来即可，勿发送密码、验证码或带登录令牌的地址。
- “采样底噪”不可用：浏览器或页面策略限制了 AudioWorklet，此时只有滤波和增益；面板会明确说明。
- 声音不对/不同步：先点击“恢复原声”；必要时刷新页面。不要反复提高增益。
- 卸载：Edge 在扩展页移除；iPad 删除脚本或停用 Userscripts 对此网站的访问即可。

## 文件

- `edge/`：Edge 可加载扩展。
- `Classroom_Enhancer.user.js`：Safari Userscripts 脚本。
- `core.js`、`denoise-worklet.js`、`build.py`：可继续修改的源代码及构建脚本。
- `tests/`：开发测试。真实浏览器测试脚本需本地安装 Playwright Chromium；DOM 测试使用 jsdom，不代表真实媒体播放测试。
