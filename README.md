# Classroom Enhancer · v1 开发预览（0.3.0）

在学校原云课堂上增加人声增强、全屏字幕、课前大纲和可点击知识点导航。不重新托管课堂视频，不默认调用付费 AI。

> 0.2.0 修复安装结构：**仓库根目录现在直接有 manifest.json。** 下载 GitHub ZIP 后解压，选择解压得到的项目文件夹即可。不再需要寻找内层 edge 文件夹。旧的 edge/ 目录仍兼容。

## 安装 Edge

1. 点击 GitHub 的 **Code → Download ZIP**，完整解压。也可下载 [Edge 专用包](downloads/Classroom_Enhancer_Edge_v0.3.0.zip)，这是更小的 Edge 专用包。
2. 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”。
3. **选择能直接看到 `manifest.json` 的文件夹。不要选择 ZIP 文件或它的上一级目录。** 专用包解压后清单就在根层。
4. 打开学校课堂录像并刷新，右上角出现“课堂增强”。
5. 如已装旧版，先禁用旧扩展，避免重复运行。加载后显示版本 0.3.0。

## 0.3.0：独立识别与字幕数据包（开发版）

仍复用学校原播放器，不从零开发播放内核，不上传到其他视频网站。

- [电脑端操作说明](processor/README.md)：选择本地音频/视频与已准备好的模型，分段识别，可中断恢复。另有命令行入口。
- 扩展中“课堂字幕数据”可导出课次 ID/时长，导入电脑生成的 classroom.json，选择学校原字幕、新识别稿或修订稿。
- 修订另存，不覆盖原识别稿；浏览器本地保存，可导出后在另一设备导入。
- 当前所选字幕进入大纲分析；切换、修改字幕或时间偏移后，旧大纲标为过期并阻止使用旧章节跳转。
- 整段音频处理完毕与内容正确是两回事；界面保留部分课堂、待核验和时间匹配提示。
- 新版 AI 导入要求带 inputIdentity，使用新版“导出 AI 分析材料”生成。旧版无来源版本的大纲不能直接作为当前结果导入。

本机模型接入是可替换的初始实现，未证明比学校字幕准确。还没有自动获取学校音轨、整课视觉分析、跨片段语义合并、已确认多路视频时间映射。首期需用户提供有权处理的本地媒体；依赖安装与模型准备仍需操作，不是免安装的一键服务。

## 功能

| 看之前 | 看之中 | 复习时 |
|---|---|---|
| 学校已有课堂总结、章节导航；可选额外 AI 大纲 | 覆盖式可调字幕、本机人声增强和采样降噪 | 搜索知识点、点击时间点跳转、标识当前章节 |

### 字幕与声音

点击“课堂增强”，面板下方有播放设置。用 **带字幕全屏** 进入包含字幕的元素全屏；系统原生视频全屏可能隐藏网页字幕。字体、颜色、透明度和位置可调，字幕可直接拖动，倍速同步沿用学校字幕。

先确认原视频正常播放，再启用音频增强。在老师不讲话、只有背景噪声时点击“采样底噪 1.5 秒”。强度过大可能发闷；关闭增强即可恢复原声。

该版本使用本机滤波、增益、限幅及采样后的频谱降噪，**不是 AI 人声分离**。针对稳定底噪和音量偏小，不能承诺清除其他人讲话或恢复丢失的词。需要额外请求同一个媒体的独立音轨，可能增加流量。若学校服务器不允许跨域音频处理，会保留原声；字幕和导航仍可用。

### 课前地图与章节导航

- 自动整合页面上的“课堂总结”和带时间点的导航。来源标为学校已有结果，不替学校保证准确性。
- 若学校懒加载内容，先展开导航/转写，再点“重新读取”。扩展不会强制开始播放。
- 搜索知识点后点击章节，控制当前主画面跳转，保留播放/暂停状态；尚未确认偏移的其他轨道不强制同步。
- “强调线索”只是包含重点/注意/考试等措辞的原字幕筛选，明确标注待核对，不伪装成 AI。

### 新增 AI 分析：免费本机或导入结果

**默认不需要模型或服务器。** 学校已有总结和导航直接可用。需要更深入分析时，有两条可选路径：

A. 电脑本机 Ollama（Edge）：自行安装 Ollama 并准备一个能处理中文的本地模型。在模型设置允许当前扩展的 origin（如需设置 `OLLAMA_ORIGINS`，只添加这一个扩展 origin；扩展 ID 可从 Edge 扩展详情查看）。填入 `ollama list` 中已有的模型名，点击“本机 AI 分析”。只连接本机 `http://localhost:11434/api/chat`，不收集 API Key，不默认下载模型。慢模型可能超时；按当前读取字幕分段请求。需自行准备本地运行环境。

B. 无本机模型 / iPad：点击“导出 AI 分析材料”，得到带时间戳的字幕和分析要求。自行交给选择的 AI，将其 JSON 结果粘贴/导入本节课面板。AI 所用账号的限制或费用由你选择的服务决定。导入后可导出大纲 JSON，在另一台设备同一课次使用。

星级是 **AI 复习建议**。有明确引文的条目仍需对照录音；无法匹配原字幕的引文不会被展示成依据。不同课次、无效或越界时间会拒绝导入；本机结果的开始时间还必须对应输入字幕。失败时保留旧结果。

页面显示读取了多少段、最后时间点和已知总时长。**只分析读到的字幕，不保证网站尚未加载的内容已被覆盖。** 长课按片段汇总，跨片段语义合并和真实模型质量仍需评估。

## iPad Safari

1. 安装 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)。
2. 在 Userscripts 中选择脚本目录，将仓库中的 `Classroom_Enhancer.user.js` 保存到该目录，保留 `.user.js` 扩展名。
3. 系统设置启用 Safari 扩展，只允许学校 `ylb.nwafu.edu.cn` 网站。
4. 刷新课堂页面，点击“课堂增强”。使用“带字幕全屏”或“网页铺满”。

iPad 可使用学校导航和导入的 AI 大纲；不把平板 localhost 当作你的电脑，故本机模型按钮会说明不支持。Safari 真实设备仍需验收，不能用桌面浏览器测试代替。

## 权限与隐私

只匹配学校云课堂路径；另允许访问本机 localhost:11434 供用户主动启动 AI。无第三方服务器、无视频上传/持久下载，无 Cookie/密码/麦克风/屏幕录制权限。字幕不自动外发；设置与用户选择的 AI 大纲存于该站点本地存储。本机 AI 仅点击按钮后发送已读取的字幕到本机服务。

## 开发

- `core.js`：字幕、音频与面板；`learning.js`：大纲/导航/导入；`background.js`：固定本机 AI 接口。
- `denoise-worklet.js`：本机频谱处理。
- `python3 build.py`：构建 Edge 和 Safari。
- `npm install` 后可运行 `npm run test:dom`、`npm run test:browser`、`npm run test:extension`。
- 浏览器测试使用 `BROWSER_EXECUTABLE` 指定已安装浏览器。扩展测试使用 `EXTENSION_DIR` 指定最终解压目录，默认仓库根目录。
- 浏览器测试页面、音频和模型响应均是合成测试夹具，不包含真实课堂内容。
